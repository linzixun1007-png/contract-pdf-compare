# 构建与部署

运行依赖 requirements-runtime.txt、构建依赖 requirements-build.txt 固定版本及 SHA-256，供 Windows x64 使用。先创建虚拟环境，再用该环境的 Python 安装依赖。离线时加 --no-index --find-links 指向 Release 的 04_离线依赖_Windows64位 文件夹。

python build_exe.py --mode both --output build 生成 folder/dist/合同PDF对比 和 single/dist/合同PDF对比.exe。PyInstaller 构建应在正常安装了 Tcl/Tk 的 Windows Python 3.12 环境进行。模式只改变分发形态，不改变比较逻辑。

Release 的 03_源码与IT部署 中，离线安装.ps1 和离线构建.ps1 支持选择安装及构建目录。请先阅读脚本，再由 IT 按单位要求运行。离线部署仍需提供合适的 Python；免安装 exe 不需要另装 Python。

Release 包同时提供程序源码、样例、固定依赖、许可与 PyMuPDF/MuPDF 上游源码。构建产物未做商业代码签名；如组织需要签名、软件准入或指定路径安装，请由 IT 自行重建和部署。
