# 一个程序中的比较档位

默认档位为严格复核。档位调整可忽略的排版与水印特征，没有“相似到一定比例就当成一致”的选项。相似度只用于把已检出的差异组织为改写、删除或新增。

| 档位 | 字符与空白 | 水印处理 | 适合场景 |
|---|---|---|---|
| 严格复核（默认） | 保留全半角、上标等字符区别及 ASCII 词／数字之间的空格；归并部分已知兼容汉字、中文排版空白 | 要求明确指定的独立医院名（可附限定标签），并结合角落位置与小字号，或旋转与大字号 | 重要合同、对型号和单位差异敏感的核查 |
| 常规合同 | 忽略中文排版空白、全半角及 Unicode 兼容字形；保留英语词／数字之间的分隔 | 结合样式／位置识别独立医院名，可尝试识别以“医院”结尾的独立名称 | 已经用真实模板验证的常规 PDF 流转 |
| 宽松排版 | 与常规档采用相同字符归一化 | 扩大右侧角落范围，独立医院名可结合跨页重复；旋转或大字号的常见独立水印标签也可识别 | 水印样式较多且已人工确认规则适合的模板 |

三个档位共同遵守：

- 内部定稿正文保留；候选水印与基准某行文字相同，则保留供比较。
- “甲方：某某医院”“合同编号”“金额”等正文不会仅凭医院名子串、字号或位置被直接删除。
- 普通数字改动、条款增加／删除进入差异检查；表格快判还核对单元边界，避免绿色结论与高亮差异矛盾。
- 无文字、疑似扫描页、无法解码字符、规范化指纹与结构结果矛盾，均进入“无法完整比较”。换档不能把这些情况强制改成通过。
- 常规及宽松档会归并部分兼容字形，例如 m² 与 m2；需要保护这类单位／符号区别时使用严格档。
- 编号后空白、中文字符间空白和中文折行不视为正文变化。例如 `(b) 条款` 与 `(b)  条款`、`研究` 与 `研 究` 可通过；`AB C` 与 `A BC`、`100` 与 `1 00` 仍会报告差异。
- 有明确矢量边框的表格按实际行、列重建，支持横向合并单元格并保留空单元格位置。文字对象的内部写入顺序可不同，但真实行重排、数值改变仍进入差异检查。跨行合并、无边框、多栏正文或异常阅读顺序仍可能误报，需要人工核对。
- 报告配对保留两份文件各自的内容顺序；未匹配行在原位置显示，避免被集中放到末尾造成错序印象。

医院名可空着运行，但严格档不会自动把未知医院名当作水印。报告记录所选档位、排除明细、程序版本、生成时间和双方原文件 SHA-256。
