# 测试范围

self_test.py 使用 37 份虚构 PDF 完成 62 项检查，覆盖档位、金额/正文修改、空格和兼容字符、水印、表格、扫描页与文字解码异常。

扫描或文字解码异常必须得到无法完整比较。原始 hospital_B_amount、hospital_C_textwm、hospital_F_narrow_amount、table_all_wm 样例含丢失字符映射，测试预期为无法完整比较，而非一致。

make_samples.py、make_samples2.py 保留原始虚构样例生成逻辑，需自行安装 ReportLab 与 Pillow。sample-subset.ttf 仅包含原始选取的部分字形，不适合生成任意中文合同；生成样例后请再次检查字形映射。仓库中的回归 PDF 是版本化测试输入。

gui.py --gui-check 检查界面组件与三个档位切换，不打开真实合同。发布包的两种 exe 均需另外运行 --self-test 与 --gui-check；这些检查不替代真实业务样本的人工试点验收。make_regression_samples.py 可重新生成回归 PDF，需 ReportLab 与 Pillow。
