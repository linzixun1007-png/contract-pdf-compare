# 测试范围

self_test.py 使用 67 份虚构 PDF 完成 139 项检查，覆盖档位、金额/正文修改、空格和兼容字符、水印、表格、扫描页与文字解码异常。

1.2.0 新增 17 份完全虚构的 ASCII PDF 和 41 项功能检查，涵盖正文跨页重排、不同纸张尺寸、分别指定 A/B、指定页范围、旋转页面坐标、部分文字行排除、框边字符保留、框外金额改动、无效规则拒绝、扫描页与空比较范围保护，以及报告句子范围和归一化高亮。`make_regression_v12.py` 仅依赖已锁定的 PyMuPDF，可重建这些文件。所有文本常量写在生成器中，不源自业务合同。

界面检查另含 8 项忽略区域交互检查：双页预览、拖动坐标与当前页、编辑副本、预设与单侧应用、应用后关闭文件、取消不提交、更换文件后重新预览、清空恢复默认范围。

1.2.0 保持版本号的表格与排版修订另外新增 14 份虚构 PDF 和 36 项检查。`make_table_regression_v12.py` 仅依赖已锁定的 PyMuPDF，可生成这些样例；内容是独立编写的通用费用表和简短条款，不读取业务 PDF。覆盖有边框表格的文字对象错序、两列合并单元格、换行表头、字体碎片、整行文字对象、空单元格位置、金额改变、真实行重排、编号空白、中文折行、英语词和数字之间的空格，以及报告保持两侧原顺序。

行重排验收使用 `table_regression_v12/grid_A.pdf` 与 `grid_reordered_B.pdf` 这组独立编写的通用费用表。条款编号与正文分成两个文字对象时，也须作为正文处理，不误认为两列表格。公开发布输入共 67 份，来源及摘要见 `样例来源.json`。

扫描或文字解码异常必须得到无法完整比较。原始 hospital_B_amount、hospital_C_textwm、hospital_F_narrow_amount、table_all_wm 样例含丢失字符映射，测试预期为无法完整比较，而非一致。

make_samples.py、make_samples2.py 保留原始虚构样例生成逻辑，需自行安装 ReportLab 与 Pillow。sample-subset.ttf 仅包含原始选取的部分字形，不适合生成任意中文合同；生成样例后请再次检查字形映射。仓库中的回归 PDF 是版本化测试输入。

gui.py --gui-check 检查界面组件与三个档位切换，不打开真实合同。发布包的两种 exe 均需另外运行 --self-test 与 --gui-check；这些检查不替代真实业务样本的人工试点验收。make_regression_samples.py 可重新生成回归 PDF，需 ReportLab 与 Pillow。
